统一形式语言（UFL）是一种用于声明变分形式有限元离散化的领域专用语言。更准确地说，它提供了一种灵活的接口，允许用户选择有限元空间，并以接近数学符号的表示法来定义弱形式表达式。

UFL是FEniCS项目的一部分。如需更多信息，请访问https://www.fenicsproject.org
